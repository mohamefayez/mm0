# AURÉA Codex Skills Pack

This pack contains 7 focused skills for the AURÉA perfume e-commerce project:

1. aurea-ui-guardian
2. nextjs-architecture
3. ecommerce-ux
4. responsive-qa
5. accessibility-review
6. code-review
7. performance-audit

## Recommended usage

Keep the skills available to Codex and invoke them when relevant.

Suggested workflow:

### During implementation
- aurea-ui-guardian
- nextjs-architecture
- ecommerce-ux

### After each page/feature
- responsive-qa
- accessibility-review

### Before merge/release
- code-review
- performance-audit

## Important

Keep `AUREA-PRD.md` in the repository root.
The project PRD remains the source of truth.
These skills enforce quality and implementation discipline.

Do not enable every skill blindly for every task. Use the smallest relevant set.
